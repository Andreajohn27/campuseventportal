# Campus Event Portal

A Java-based web application developed to manage and register for campus events.

### Features
- Student event registration
- Event details and listings
- Login and registration
- Admin login and dashboard
- Event management
- Event images and information

### Technologies
Java • Servlets • HTML/CSS • NetBeans • GlassFish

### Project
This project was developed as a full working campus event management application using Java Servlets and GlassFish.
